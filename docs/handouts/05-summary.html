What now exists

  • A paper goes in, a running program comes out. Two papers have made the whole journey — PDF, to understanding, to code, to a real training run.
  • It fixes its own mistakes. We deliberately broke a generated script; the system ran it, saw the crash, worked out what was wrong, rewrote that part, and got it working — first try.
  • It follows the paper, not its own memory. Shown on a paper whose method is unusual enough that memory would have produced something else entirely.

What is still missing

  • The comparison. Nothing yet takes the number we produced and checks it against the number the paper claimed. That check is the entire point of the project, and it does not exist yet.
  • The written report that would come out at the end.
  • Enough computing power to make any of the numbers meaningful.

The one thing to understand. Everything built so far proves the machinery works. None of it yet proves a paper was successfully reproduced — because the step that would check that has not been built, and because the runs so far are short tests rather than real training.

Saying “ReproBot reproduces papers” today would be wrong. Saying “ReproBot reads a paper, writes the code, and runs it” is exactly right.
